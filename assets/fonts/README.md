# Self-hosted fonts

Plus Jakarta Sans (Tokotype) and DM Mono (Colophon) are both licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). The files here are the Latin and Latin-Extended subsets, downloaded from Google Fonts on 2026-10-01, so the cleaner page keeps its typography offline. Declared in `../css/fonts.css`.

Manrope (The Manrope Project Authors) is the Operations workspace UI font. Its variable Latin and Latin-Extended subsets were downloaded from Google Fonts on 2026-10-04. The original license is retained in `Manrope-OFL.txt`. The earlier fonts remain available to legacy components. No external font request is needed by either app shell.
